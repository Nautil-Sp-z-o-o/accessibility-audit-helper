Privacy Policy for Accessibility Audit Helper

Last updated: August 17, 2026

Accessibility Audit Helper is a browser extension designed to support manual WCAG 2.2 accessibility audits.

Website content

The extension may access and process the content and structure of webpages selected by the user. This may include DOM elements, text, links, images, attributes, styles and other information required to perform accessibility checks.

Website content is processed locally in the user's browser. Accessibility Audit Helper does not transmit audited website content to the developer or to external servers.

Locally stored settings

The extension may store preferences locally using the browser storage API. These preferences may include interface language, appearance, WCAG level and configuration of audit tools.

These settings are used only to preserve the user's extension configuration between sessions.

Data sharing

Accessibility Audit Helper does not sell user data, share user data with third parties, use user data for advertising or use user data for profiling.

Remote code

Accessibility Audit Helper does not use remotely hosted executable code. The extension's executable code is included in the extension package.

External links

The extension may provide a link to an external support page. The page is opened only after an explicit action by the user.

Chrome Web Store Limited Use

Accessibility Audit Helper's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

Questions regarding this privacy policy can be submitted through the project's GitHub repository.
